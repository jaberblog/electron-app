# راهنمای گرفتن خروجی EXE با گیت‌هاب

1. یک ریپازیتوری جدید در GitHub بساز.
2. محتوای همین پوشه (همه فایل‌ها از جمله پوشه `.github`) را داخل ریپازیتوری آپلود/پوش کن.
3. به تب **Actions** برو. بیلد به‌صورت خودکار شروع می‌شود (یا از **Run workflow** دستی اجرا کن).
4. بعد از تمام شدن بیلد (حدود ۳ تا ۵ دقیقه)، پایین صفحه‌ی همان اجرا، در بخش **Artifacts** فایل `windows-exe` را دانلود کن.
5. داخل zip دو فایل هست:
   - `MyApp-Setup-1.0.0.exe` — نصب‌کننده
   - `MyApp-Portable-1.0.0.exe` — نسخه‌ی قابل‌حمل، بدون نصب

## اجرای محلی (اختیاری)
```
npm install
npm start
```
